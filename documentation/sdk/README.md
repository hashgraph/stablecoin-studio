# Stablecoin Studio SDK

The **Stablecoin Studio SDK** is the core TypeScript library empowering the Stablecoin Studio ecosystem. It provides a high-level abstraction for issuing, managing, and operating stablecoins on the Hedera network, with a pipeline-based execution engine supporting multiple signing backends (Hedera Client, ethers Signer, WalletConnect, custodial providers, and multi-signature coordination).

## Installation

```bash
npm install @hashgraph/stablecoin-npm-sdk
```
